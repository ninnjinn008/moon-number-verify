# 巨大数庭園数に対抗する数 N の定義（審議用・改訂68）

本書で定義する数 N は、月絶天葬数（N\_Moon）と呼ぶ。N\_Moon = N である。

## 0. 要旨

- 数 N は、構成可能宇宙 L における最小の Mahlo 基数 κ について、構造 M = (V\_{κ+1})^L 上の純粋な ∈-論理式による定義可能性（Rayo 型）で定義する。
- 評価は L で行う。必要な前提は「（真の宇宙 V に）Mahlo 基数が存在する」ことのみである。Mahlo 性は L に下方絶対的なので、このとき L にも Mahlo 基数が存在し、L は理論 S = ZFC + V=L + 「Mahlo 基数が存在する」のモデルになる。
- 主張は三つである。(1) 定義文は標準的な Rayo 型で、追加記号・パラメータ・選択関数を一切用いない。(2) 巨大数庭園数（LNGN）を N と同じ宇宙 L で評価し、その解釈が V\_{κ+1} の元として符号化され、M の中で短い式で書けるなら、LNGN はその解釈の下で N より小さい（別紙 B）。(3) 新規性の拠り所は、Mahlo 基数 κ を用いて評価構造 V\_{κ+1} そのものを選んでいる点にある。証明力の強化ではない（別紙 C）。
- **比較の前提（審議で最初に確認したい点）。** 主張 (2) は、次の二つが認められて初めて成り立つ。
  1. **共通の評価宇宙。** LNGN も L で評価する。V ≠ L の場合、V で評価した LNGN は L の外の集合を使いうるので、M の中では名指せない。
  2. **解釈の範囲。** LNGN の公理 U3 は |U(α)| = V\_β となる β の存在しか要求しないため、U(α) を κ より上に置く解釈も許される。本書の支配はそのような解釈には及ばない。本書が主張するのは「V\_{κ+1} の元として符号化され、M の中で短く定義できる解釈 I の下での LNGN\_I」に対する支配である。さらに、追加の定数記号の解釈を動かすだけで LNGN\_I はいくらでも大きくなる（別紙 B「解釈全体にわたる非有界性」）。したがって、解釈を固定しない限り LNGN は単一の自然数として定まらない。

## 1. 前提、基礎理論と評価構造

**前提。** 真の宇宙 V に Mahlo 基数が存在すると仮定する。

**評価モデルの固定。** V の Mahlo 基数 μ は L においても Mahlo 基数である。実際、V で正則な基数は L でも正則である。また μ は V で極限基数であり、V の基数は L でも基数なので、μ 未満の L の基数は非有界に存在し、μ は L でも極限基数である。L では GCH が成り立つので、μ 未満の L の基数 λ について (2^λ)^L = (λ^+)^L < μ となり、μ は L で強極限である。よって μ は L で到達不能である（正則性と GCH だけでは強極限性は出ない。たとえば ℵ\_1 は正則だが強極限ではない。極限基数であることを経由する必要がある）。また、V で正則な基数は L でも正則なので、μ 未満の L の正則基数の集合は、V の正則基数の集合を含む。L に属する μ の閉非有界集合は V でも閉非有界であり、V の正則基数の集合は V で定常だから、L のどの閉非有界集合も V の正則基数の集合と交わり、ゆえに L の正則基数の集合とも交わる。よって μ 未満の L の正則基数の集合は L においても定常である。μ は L で到達不能なので、μ 未満の L の強極限基数の集合は L で閉非有界であり、これと交わることで、μ 未満の L の到達不能基数の集合も L で定常になる。より直接には次のようにも言える（改訂35 で追記。別の AI による審査の提案）。μ 未満の V の到達不能基数 ν は L でも到達不能である（V で正則なら L で正則、V で極限基数なら L でも極限基数で、L の GCH により強極限）。L の閉非有界集合は V でも閉非有界であり、μ は V で Mahlo なので V の到達不能基数の集合はそれと交わる。したがって L の到達不能基数の集合は L のどの閉非有界集合とも交わり、L で定常である。したがって L ⊨ S、ただし

```
S = ZFC + V=L + 「Mahlo 基数が存在する」
```

である。以後、すべての定義と評価は L の中で行う。言い換えれば、S の意図されたモデルを L に固定する。

**κ と M。** L における最小の Mahlo 基数を κ とする。κ は L の Mahlo 基数全体のうち ∈-最小のものとして一意に定まる。評価構造を

```
M = (V_{κ+1}, ∈)   （L の中で計算する。すなわち (V_{κ+1})^L）
```

とする。V\_{κ+1} は集合であり、∈ は通常の所属関係である。V=L の下で V\_κ = L\_κ である。

追加の定数記号、関数記号、関係記号、Henkin 定数、Skolem 関数、真理述語、パラメータは一切使用しない。特に Θ のような選択関数記号は導入しない。

自然数はフォン・ノイマン自然数として同一視する。すなわち 0 = ∅、n+1 = n ∪ {n} である。ω は L と V で一致するので、以下で定まる自然数 N は V の自然数としても同じものである。

## 2. 形式言語と文法

基本記号のアルファベットは次の有限集合とする。

```
{ x, ′, ¬, ∧, ∀, ∈, =, (, ) }
```

変数記号は、x と有限個のプライム ′ からなる有限語 x, x′, x′′, x′′′, … とする。プライムも通常の 1 記号として数える。

L-式は、次の生成規則で定まるものに限る。

1. 変数 u, v に対し、(u ∈ v) および (u = v) は原子式である。
2. φ が式なら ¬φ は式である。
3. φ, ψ が式なら (φ ∧ ψ) は式である。
4. φ が式で u が変数なら ∀u φ は式である。
5. 以上を有限回適用して得られるもののみが式である。

∃、∨、→ などは略記であり、記号数は ¬, ∧, ∀ による展開後の式について数える。

式 φ の記号数 |φ| は、変数を構成する x とプライムを含め、各基本記号を 1 として数えた総数とする。文法が再帰的に固定されているため、各式の記号数は一意に決まる。

## 3. 一意定義可能性

L の中で、各 L-式 φ と各自然数 n に対し、変数 x に n を割り当てたときの充足関係 M ⊨ φ\[n\] を、M が集合構造であることを用いて Tarski の再帰によって定める。数値 n は対象言語内の項として書かず、外の理論における割当て x ↦ n によって指定する。

自然数 n が「k 記号未満の式によって M において一意に定まる」とは、自由変数がちょうど x のみである L-式 φ(x) で、次を満たすものが存在することとする。

```
|φ| < k  かつ  M ⊨ ∃!x φ(x)  かつ  M ⊨ φ[n]
```

## 4. 関数 F

各 k に対し、

```
D_k = { n ∈ ℕ : n は k 記号未満の式で M において一意に定まる }
```

とおき、

```
F(k) = 1 + max D_k   （D_k が空でないとき）
F(k) = 1             （D_k が空のとき）
```

と定義する。

**全関数性。** 有限アルファベット上で長さ k 未満の語は高々有限個であり、各式が M において一意に定める自然数は高々 1 個である。したがって D\_k は有限であり、F(k) は常に自然数として定まる。一般の集合構造に対する「F 相当の関数が全域である」という事実は ZFC 内で証明できる。本定義の F は L における M を用いるため、この特定の F の全関数性は S の中で証明される。Mahlo 基数の存在と V=L は、全関数性の一般原理のためではなく、評価構造 M を固定するために用いられる。

**単調性。** D\_k ⊆ D\_{k+1} であるから、F は広義単調増加である。

## 5. 補題：y ≥ 10^100 で F(y) > y

**主張。** 10^100 以上のすべての自然数 y に対し、y 以上のある自然数が y 記号未満の L-式によって M において一意に定まる。したがって max D\_y ≥ y であり、

```
F(y) = 1 + max D_y ≥ 1 + y > y
```

が成り立つ。

y そのものを名指す必要はない。y 以上の数を一つ短く名指せば足りる。そこで二進展開による数詞ではなく、冪集合の反復で急増する数 |V\_j| を用いる。この方式では式の形が単純で、記号数を実際に数えて証明にできる。

### 5.1 式 Big\_j(x)

各 j ∈ ℕ に対し、L-式 Big\_j(x) を次の部品から組み立てる（∃、∨、→、↔ は ¬, ∧, ∀ による略記で、記号数は展開後に数える）。

- Empty(a)：∀e ¬(e ∈ a)。
- Trans(a)：∀z (z ∈ a → ∀u (u ∈ z → u ∈ a))。
- Succ(z)：∃w (w ∈ z ∧ ∀u (u ∈ z ↔ (u ∈ w ∨ u = w)))。
- Nat(a)：Trans(a) ∧ ∀z (z ∈ a → ∀u (u ∈ z → ∀w (w ∈ u → w ∈ z))) ∧ ∀z ((z ∈ a ∨ z = a) → (Empty(z) ∨ Succ(z)))。
- PowerOf(a, b)：∀z (z ∈ a ↔ ∀u (u ∈ z → u ∈ b))。
- Chain\_j(v)：Chain\_0(v) は Empty(v)。Chain\_{j+1}(v) は ∃w (PowerOf(v, w) ∧ Chain\_j(w))。変数 v, w は x′ と x′′ を交互に使う。
- Pair(p, a, b)：∀s (s ∈ p ↔ (∀t (t ∈ s ↔ t = a) ∨ ∀t (t ∈ s ↔ (t = a ∨ t = b))))。すなわち p = {{a}, {a, b}}。
- Equi(a, b)：a と b の間の全単射 g が存在する。すなわち ∃g について、g の元はすべて a × b の順序対であること、全域性、全射性、関数性、単射性の 5 条件の連言。

そして

```
Big_j(x) ≡ Nat(x) ∧ ∃v (Chain_j(v) ∧ Equi(x, v))
```

とおく。

### 5.2 意味：Big\_j は |V\_j| を一意に定める

M = V\_{κ+1} は推移的で、基礎の公理を満たす。以下、M の中での解釈が真の意味と一致することを確かめる。

- **Nat(x)。** 推移的集合で、その元もすべて推移的なものは、基礎の公理の下で順序数である。さらに x 以下の順序数がすべて 0 か後者であることから、x は自然数である。逆に自然数はこれらを満たす。
- **Chain\_j(v)。** V\_j は遺伝的有限集合であり、その部分集合はすべて M に属する。よって M の中の PowerOf は真の冪集合を与え、外延性により Chain\_j(v) を満たす v は V\_j ただ一つである。
- **Equi(x, V\_j)。** x と V\_j はともに有限なので、その間の全単射は遺伝的有限集合として M に属する。第 5 節の順序対の式 Pair は改訂28 までの別紙 B と同じ有界でない形だが、Equi の中では成分が x と V\_j の元（有界量化で取り出した遺伝的有限集合）に限られる。M はそれらの一元集合・二元集合をすべて含むので、Pair の判定は正しく、全単射の定義も M の中で正しい（別紙 G「注意（改訂29）」の偽の陽性は、成分が最上位の元のときにしか生じない）。

以上より、M ⊨ Big\_j\[x\] となる x は |V\_j| ただ一つである。ここで |V\_0| = 0、|V\_{j+1}| = 2^{|V\_j|} であり、

```
|V_1| = 1, |V_2| = 2, |V_3| = 4, |V_4| = 16, |V_5| = 65536, |V_6| = 2^65536
```

となる。Big\_j(x) の自由変数は x のみである。

### 5.3 記号数（機械的に計数）

補題の数学的な証明は 5.1・5.2・5.4 で完結しており、プログラムが担うのは記号数 6659 + 114 j という数値の計数と、部品の意味の補助的な確認である。記号数は手で数え直すこともでき、また上限 10^100 に対して桁違いの余裕があるので、仮に計数が数倍ずれていても 5.4 の結論は変わらない。

Big\_j(x) を原始記号まで展開して記号数を数えるプログラム（付録 `num_formula.py`）を用いた。プログラムは次を確認する。

- 生成した式がアルファベット {x, ′, ¬, ∧, ∀, ∈, =, (, )} だけからなること。
- 自由変数が x のみであること。
- 各部品の引数が、その部品の内部で束縛する変数と重ならないこと（変数捕獲がないこと）。
- 記号数を、文字列の長さと構文木の再帰計算の 2 通りで数え、一致すること。

また、部品 Empty、Trans、Succ、Nat、PowerOf、Pair については、有限の推移的集合 V\_4（16 元）上で総当たり評価し、意図した意味と一致することを確認した（付録 `test_semantics.py`）。Equi は量化をすべて有界にしたうえで、全単射の候補を含む 74 元の推移的集合上で、x ∈ {0,1,2,3} と 4 通りの b について「全単射がある ⇔ x = |b|」を総当たりで確認した（付録 `test_equi.py`）。単射性の条件を外した版ではこのテストが 5 件の不一致を出すので、テストは誤りを検出できる。

結果は

```
|Big_0| = 6659、 Chain の 1 段ごとの増分は 111 または 114
```

であり、Chain の構造からすべての j について

```
|Big_j| ≤ 6659 + 114 j
```

が成り立つ。たとえば |Big\_6| = 7334 である。

### 5.4 補題の証明

y ≥ 10^100 とし、|V\_j| ≥ y となる最小の j をとる。|V\_5| = 65536 < 10^100 ≤ y なので j ≥ 6 である。

- **j = 6 のとき。** |Big\_6| = 7334 < 10^100 ≤ y。
- **j ≥ 7 のとき。** j の最小性から y > |V\_{j−1}| である。k ≥ 6 について |V\_k| ≥ 2^{k+40} が成り立つ（k = 6 では 2^65536 ≥ 2^46、帰納段階では |V\_{k+1}| = 2^{|V\_k|} ≥ 2^{2^{k+40}} ≥ 2^{k+41}）。よって y > 2^{j+39}。一方 |Big\_j| ≤ 6659 + 114 j < 2^{13}(1 + j) ≤ 2^{13} · 2^j < 2^{j+39} である。

いずれの場合も |Big\_j| < y となる。したがって |V\_j| ∈ D\_y かつ |V\_j| ≥ y であり、F(y) ≥ 1 + |V\_j| > y が従う。□

### 5.5 注：数そのものを名指す式 Num\_y

y を正確に名指す式 Num\_y(x)（二進展開と Horner 法による標準的な構成）も存在する。本補題には不要だが、別紙 C 第 5 項で用いる。改訂64 で具体的に構成し、y ≥ 1 について |Num\_y| ≤ 145 + 22,724 (B − 1)（B は y の二進の桁数）であることを数えた（別紙 C「第 5 項の定数の評価」、付録 `fsub.py`）。

## 6. 目的の数

```
N = F^{F(10^100)}(10^100)
```

ここで F^0(x) = x、F^{m+1}(x) = F(F^m(x)) であり、F^{F(10^100)} は F の F(10^100) 回の反復合成である。

補題より F(10^100) > 10^100 である。反復の各段の値は 10^100 以上なので補題が適用でき、F は各段で真に増加する。F(10^100) ≥ 2 であるから、F(10^100) < F^{F(10^100)}(10^100) = N が成り立つ。

これを N の完全な定義とする。

# 別紙

## A. 用語

本別紙において「1-到達不能基数」とは、到達不能基数であり、かつ到達不能基数の極限である順序数を意味する。流儀によって添字の付け方が異なるため、本定義ではこの語をこの意味で固定する。

## B. 支配（条件つき）

**f の形（原文で確認済み）。** ブログ「巨大関数」節の定義は次のとおりである。

- IsDefinition(P)：「ある ┌x\_0┐ が存在し、P を満たし、かつ任意の ┌x\_1┐ に対し (P)\[┌x\_1┐/┌x\_0┐\] ならば ┌x\_1┐ ┌=┐ ┌x\_0┐ を満たす」という ┌L┐ 論理式。
- Definable(x\_0, x\_1, x\_2)：「x\_1 ∈ ℕ かつ x\_2 ∈ Formula かつ U(CNF(x\_1)) ⊨ IsDefinition(x\_2) かつ U(CNF(x\_1)) ⊨ (x\_2)\[Parameter(x\_0)/┌x\_0┐\]」という L 論理式。
- f(n)：i ∈ n かつ P ∈ Formula かつ MetaCode(P) ∈ n かつ Definable(m, i, P) を満たす i と P が存在するような m ∈ ℕ の総和。
- 巨大数庭園数は f^10(10↑^10 10) である。

最大値ではなく総和だが、和をとる範囲は有限なので、f(n) の M での定義可能性には影響しない。

**P は Formula（Θ を含む式を含む）を動く。** P は Θ だけでなく、追加の定数記号 ┌c\_i┐、関数記号 ┌f\_{a,i}┐、関係記号 ┌r\_{a,i}┐ も含みうる。したがって f の値は、U(CNF(i)) におけるこれらすべての記号の解釈に依存する。公理 U1〜U3 はそれらを一意に決めないので、LNGN は T のモデル（とくに関数 U の選び方）ごとに値が変わりうる。本書が LNGN\_I という書き方で解釈 I を明示する理由はここにある。原文も「Θ 以外に付け加えた記号に大して意味がない」と述べており、追加記号を最も単純に解釈する本書の候補は、この趣旨と矛盾しない。

**解釈の定義。** LNGN の f は、順序数 CNF(i)（i < n）に対する構造 U(CNF(i)) の中での定義可能性を用いる。原文（ブログ「巨大関数」節）では CNF は ℕ から ε0 への写像として定義され、カントール標準形により全射であると明記されている。したがって f が参照する順序数はすべて ε0 未満である（原文で確認済み）。U(α) を言語 ┌L┐ の構造として扱うには、U、Θ、および追加された定数・関数・関係記号の解釈が必要である。LNGN の公理 U1〜U3 だけでは、Θ と追加記号の解釈が一意に決まるとは限らない。そこで、これらの解釈全体を「解釈 I」と呼び、I を与えたときの LNGN を LNGN\_I と書く。

**評価宇宙の一致。** 本別紙では、LNGN も N と同じく L の中で評価する（要旨「比較の前提」1）。以下の V\_κ、V\_{λ\_α}、<\_L はすべて L の中で計算したものである。LNGN を真の宇宙 V で評価する立場をとる場合、V ≠ L ならば V\_{λ\_α}^V ≠ V\_{λ\_α}^L となりうる。このとき LNGN\_I は M の外の集合に依存し、命題 B は適用できない。

- よって f(f(A)) ≥ m であり、f(f(A)) > MetaCode(P)
- 以下同様に、各段の値は MetaCode(P) を上回り続ける

**Henkin 公理と自由変数（要確認・重要）。** 原文の Formula₋ は「Θ を含まない ┌L┐ 論理式全体」であり、x\_i 以外の自由変数をもつ式を除外していない。一方、Θ は引数としてコード MetaCode(P) しか受け取らない。構造が論理式を満たすことを「すべての割当てで成り立つ」と読む標準的な規約では、たとえば i = 1、P = (┌x\_1┐ ┌∈┐ ┌x\_2┐) について、x\_2 に相異なる一元集合 {a}, {b} を割り当てると、Henkin\_{1,P} は Θ(MetaCode(P)) = a かつ = b を要求し、充足できない。この読みでは ZFC̄\_{┌L┐} はモデルをもたず、公理 U1 により T は矛盾する。

したがって LNGN が well-defined であるためには、Henkin 公理を次のいずれかの修復された読みで解釈する必要がある。

1. Henkin\_{i,P} の対象を、自由変数が ┌x\_i┐ のみの式に制限する。
2. 余分な自由変数を存在量化で閉じてから適用する。

本書の候補解釈は読み 1 を採る。どの読みを正準とするかは、審議で相手方に確認したい（別紙 E の審議事項 2）。なお、i ≠ 0 で P が ┌x\_0┐ を自由に含む場合の扱い（Code(P) の ┌x\_0┐ との衝突）も同じ問題に属する。

以上が埋まるまで、LNGN への支配は条件つきの主張として扱う。

**順序数と到達不能基数（付録 `ordinals.py`、`test_ordinals.py`、改訂24 で追加）。** 次の判定式を構成した。

- ordinal(x)：x は推移的で、x の元もすべて推移的（基礎の公理の下で順序数と同値）。138 記号。
- is\_omega(w)：w は最小の極限順序数（0 でも後者でもない順序数で、それより小さい順序数はすべて 0 か後者）。
- func(f, A, B)・bij(f, A, B)：f は A から B への関数・全単射（順序対の集合として）。
- regular(λ)：β < λ と f : β → λ のどれについても、f の値をすべて上から抑える γ < λ がある。
- strong\_limit(λ)：β < λ のどれについても、P(β) と全単射でつながる γ < λ がある。
- inaccessible(λ)：順序数で、ω < λ、正則、強極限。52,904 記号。

**検証（順序数と到達不能基数）。** 判定式が定義を正しく書き写しているかを、有限の場合について定義どおりの総当たりと照合した。ordinal は V\_3 の全元と有限順序数で、func・bij は小さな集合の間の全関係で、regular・strong\_limit は有限順序数 n ≤ 5 について（宇宙には必要な関数・冪集合・全単射をすべて入れた）照合し、すべて一致した。正則性の上界を λ 自身まで許した変異版は 3 件の不一致で検出された。**限界：** 有限の宇宙には ω も到達不能基数もないので、is\_omega と inaccessible は「すべて偽になる」ことしか確かめられない。無限の場合の正しさは、各条件が定義の直訳であること（V\_{κ+1} は λ < κ について必要な関数と冪集合をすべて含むので、量化の範囲が足りる）による数学的な議論に頼る。

**O と L（付録 `inacc_seq.py`、`test_inacc_seq.py`、改訂24 で追加）。** 名前（自然数）と本物の順序数をつなぐ。

- O(i) = { O(k) : k ∈ ω, CNF(k) < CNF(i) }。フォン・ノイマン順序数は自分より小さい順序数の集合なので、CNF が ε0 への全射であることから、CNF(i) の大きさに関する帰納法で O(i) = CNF(i) となる。比較は上の「CNF」の cnf\_lt を使い、順序数の足し算や ω の冪を集合の上で定義する必要はない。o\_ok(Of, W) は「Of は W 上の関数で、各 i ∈ W について上の等式が W の中で成り立つ」、ord\_of(i, x) は「ω 上でそれを満たす Of があり、Of(i) = x」（25,726,353 記号）。
- ε0 は O の値域として定める（eps0）。
- L(β) は「γ < β のすべての L(γ) より大きい最小の到達不能基数」（= β 番目の到達不能基数 λ\_β）で、定義域は ε0。lam\_of(β, λ) は「ε0 上でそれを満たす表があり、その β での値が λ」（31,306,190 記号）。κ は Mahlo なので到達不能基数は κ の下で非有界、κ は正則なので表は存在して V\_κ に属する。

**検証（O と L）。** 本物の ω・ε0・到達不能基数は有限の宇宙に入らないので、縮めて確かめた。O は、名前の範囲を CNF の値が有限になる名前（0〜39 のうち 26 個、値 0〜3）に限り、正しい表が受理され、値を一つずらした表と定義域の欠けた表の 31 個がすべて拒否されることを確かめた（cnf\_lt は検証済みなので代用関係）。L は「到達不能」を有限順序数の集合 S = {2, 4, 5, 7, 9, 11} への所属に差し替え、定義域 5 で、正しい表が受理され偽の表 20 個がすべて拒否されることを確かめた。変異テストでは、O の「小さい名前の値はすべて O(i) に入る」条件を外した版が偽の表を 10 個、L の最小性を外した版が 1 個受理し、どちらも検出された。

**構造 U(α)（付録 `structure.py`、`test_structure.py`、改訂24 で追加）。** 充足関係 sat に渡す構造 (dom, E, Cn, Fn, Rel) を、候補解釈 I の下での U(CNF(i)) として定める。

- vstage(λ, D)：D = V\_λ。「R(0) = ∅、R(β+1) = P(R(β))、極限 β では R(β) = ⋃\_{γ<β} R(γ)」を満たす λ+1 上の関数 R が存在し、R(λ) = D（19,550 記号）。
- e\_restrict(D, E)：E は ∈ を D に制限したもの。
- cn\_ok(Cn)：すべての定数記号 c\_i を ∅ と解釈する。rel\_empty(Rel)：∈ 以外の関係記号はすべて空関係。
- fn\_ok(Fn, D, α, SU)：f\_{a,i} は D^a のすべての引数列に ∅ を返す。U は、x が順序数で x ∈ α なら構造の表 SU の値 SU(x)（構造 U(x) そのもの）、そうでなければ ∅。改訂30 までは SU を使わず V\_{L(x)}（領域だけ）を値としていたが、これは原文の U2 を満たさない（上記「修正履歴（U2、改訂31）」）。SU を与えない旧版も比較のためにコードに残してある。Θ は D から D への関数（59,451,742 記号）。

**Θ の扱い。** 構造 U(α) のうち Θ の部分は、下記「<\_L と Θ」で定める。struct\_of は Θ の解釈を「D 上の関数」という条件だけで受け取り、それに <\_L による条件を加えたものが struct\_full である。

**検証（構造 U(α)）。** vstage は λ = 0〜4 で、D の候補 V\_0〜V\_4 のうち D = V\_λ のときだけ真になることを確かめた（宇宙には正しい R と 1 段ずらした偽の R を入れた）。e\_restrict は V\_3 上で正しい表を受理し、1 組の過不足のある表を拒否した。cn\_ok は、定数記号 c\_0, c\_1 の現れる宇宙で正しい表を受理し、欠けた表と値の違う表を拒否した。fn\_ok は D = V\_3、α = 2、L(0) = 1, L(1) = 2 と差し替えて、正しい表を受理し、U(1) の値を V\_1 にずらした表・f\_{1,0} の値が一つ欠けた表・Θ が全域でない表・α の外の U の値が ∅ でない表の 4 個をすべて拒否した。**限界：** 極限段階の場合（V\_ω など）は有限の宇宙に現れないので、vstage の極限の条件は総当たりでは確かめていない。

**<\_L と Θ（付録 `lorder.py`、`test_lorder.py`、改訂25 で追加）。** 構成可能宇宙の段階 L\_β と整列順序 <\_L を書き下し、それを使って Θ の解釈を一意に定めた。

- **純粋な式と定義可能性。** ┌L┐ の式のうち、記号が変数・┌∈┐・論理記号・括弧だけのものを純粋な式と呼ぶ（def\_code：番号 n が純粋な Formula₋ の式の MetaCode）。純粋な式 P（番号 n）とパラメータ τ（P に現れる変数の添字のうち 0 以外から X への関数）について、y = { z ∈ X : (X, ∈) ⊨ P[x\_0 := z, 他は τ] } のとき「(n, τ) は X 上で y を定義する」とする（defines、322,000,256 記号）。充足関係は上の「充足関係」の sat をそのまま使う（定数・関数・関係記号の解釈は空）。等号は ∈ と外延性で表せるので、純粋な式に限っても Def は変わらない。
- **定義の表。** X 上の定義をすべて集めた集合 DT = { ((n, τ), y) } を一度だけ導入し（def\_table）、以後は DT の元を参照する。部品を何度も展開しないための工夫である（別紙 B の数詞 A の節と同じ方針）。
- **定義の順序。** (n, τ) ≺ (n′, τ′) ⟺ n < n′、または n = n′ かつ τ が τ′ より辞書式で小さい（添字の小さい順に比べ、最初に値が異なる添字で <\_β により比べる）。n が同じなら τ の定義域は同じで、<\_β が整列順序なら ≺ も整列順序である。
- **段階と順序（l\_order）。** L\_0 = ∅。L\_{β+1} = Def(L\_β) で、<\_{β+1} は「L\_β の元どうしは <\_β、L\_β の元は新しい元より前、新しい元どうしは最小の定義の ≺ の順」。≺ が整列順序なので、「a の最小の定義 ≺ b の最小の定義」は「a のある定義が b のどの定義よりも小さい」と同値であり、そのまま DT の上の有界量化で書ける。極限では和集合をとる。各段は前の段の終切片への延長なので、和も整列順序である。これは Gödel の <\_L の一つの具体化である（式の番号の付け方とパラメータの比べ方だけが流儀による）。l\_order(λ, D, W) は「λ+1 上の段階の表があり、その λ での値が (D, W)」（2,231,892,867 記号）。外側の宇宙 L では、L で到達不能な λ について V\_λ = L\_λ である。M = (V\_{κ+1})^L 自身は ZF のモデルではなく、M の中で V = L が成り立つわけではない（改訂26 までの「M では V = L が成り立ち」は誤りだったので改めた。別の AI による審査の指摘）。段階の表とその証人はすべて V\_κ ⊆ M に属し、各条件は V\_κ の元について絶対的なので、M で評価しても L における本物の L\_β と <\_β が得られ、D = V\_λ の上の順序になる。表は V\_{λ+3} に属し、λ < κ なので M に属する。
- **Θ（theta\_L、671,422,147 記号）。** m ∈ D について、m が Formula₋ の式 P の番号なら、Z = { σ : σ ⊨ P }（σ は P に現れる変数の上の割当て）として、
  - good(a) ⟺ P に現れるどの変数 x\_i についても、「P の真偽が x\_i の値だけで決まり、かつ Z ≠ ∅」ならば、すべての σ で σ[i := a] ⊨ P
  - Θ(m) は good な元のうち <\_λ で最小のもの。
  
  m が Formula₋ の式の番号でなければ Θ(m) = ∅。P の真偽が一つの変数 x\_i だけで決まり、しかも定数でないなら、i は一つに定まり（二つの変数のどちらか一方だけで決まるなら定数である）、Θ(m) は P を満たす最小の元になる。P が定数（つねに真またはつねに偽）なら、どの元も good で、Θ(m) は <\_λ の最小元 ∅ になる。二つ以上の変数に依存する P でも、どの元も good で Θ(m) = ∅ になる。
- **Henkin 公理の成立。** 読み 1 の Henkin 公理の対象（自由変数が ┌x\_i┐ だけの Formula₋ の式 P）は、真偽が x\_i の値だけで決まる。P が定数でなければ Θ(MetaCode(P)) は P を満たす元なので公理が成り立ち、定数なら公理は自明に成り立つ。全称閉包の読みでも同じである。P は Θ を含まないので sat は Fn の Θ の部分を参照せず、Θ についての条件は循環しない。U・f・定数・関係記号の解釈は Θ より先に固定されている。

## C. 新規性

以下の項目は、規則上の「相手の数に使われていない理論」という新規性の根拠であり、数の大小の根拠ではない。大小の根拠は、別紙 B の定義可能性による直接の対角化（LNGN\_I が M の中で短い式で定義できれば LNGN\_I < F(10^100)）だけに置く。巨大基数の強さと数値の大小は、直接には対応させない。

**LNGN 原文の主張との関係。** LNGN の原文は、基礎理論 ZF\_L を BS 集合論に弱めても、ZFC に強めても、階層内階層基数公理を課しても、最終的な巨大数の大きさは変わらないと述べ、理論の証明力よりも定義力・表現力が重要だとしている。本書はこの見解に同意する。そのうえで、本書の新規性は「基礎理論に強い公理を足したこと」ではなく、**Mahlo 基数 κ を使って評価構造 V\_{κ+1} そのものを選んでいること**にある。

- 基礎理論の公理を強めても、定義に使う構造が同じなら、定義可能な自然数は変わらない。原文の主張はこの場合についてのものである。
- 本書では、Mahlo 基数の存在は κ を名指して M = V\_{κ+1} を固定するために用いる。構造が大きくなり、名指せる集合（たとえば LNGN の候補解釈全体）が増えることが、定義力の増大の源である。
- したがって、原文の「公理を強めても大きさは変わらない」という主張は、本書の新規性の主張と衝突しない。

1. LNGN の定義には、宇宙の列 U(α)、Henkin 拡張、二階集合論および MK+ の埋め込みが現れる。Mahlo 基数の存在公理、特に「到達不能基数が定常集合をなす」という反射性は現れない。
2. LNGN の理論 T\_LNGN は、到達不能基数（Grothendieck 宇宙）の存在から解釈できる。LNGN の記述自身がこのことを述べている。
3. Henkin 公理を修復した版の理論を T′\_LNGN と書く。S は、(V\_{λ0}, ∈, U\_I)（λ0 は最小の 1-到達不能基数）が T′\_LNGN のモデルになることを証明する。したがって S ⊢ Con(T′\_LNGN) である。S が無矛盾なら、T′\_LNGN ⊬ Con(S) となる（証明は下の「第 3 点の証明」。改訂57 で主張から証明に改め、改訂58 で補題 K を補った）。原文どおりの T\_LNGN は、標準的な読みでは矛盾する可能性があるので（別紙 B「Henkin 公理と自由変数」）、Con(T\_LNGN) は主張しない。

である。F\_{λ′}(k) ∈ D\_{|Φ|+1} なので、F の定義から次が得られる。

## D. V=L の役割

本定義は、評価モデルを L に固定する（第 1 節）。V=L は、その固定を理論の側から表したものである。

1. **評価モデルの固定。** κ、M、F、N はすべて L の中で定義・評価される。真の宇宙 V が L と異なっていても、N は「L における値」として一意に定まる。V で Mahlo 基数が存在すれば L でも存在するので、追加で必要な前提は V における Mahlo 基数の存在だけである。
2. **Θ の正準な固定。** 別紙 B の候補構成において、Θ を <\_L 最小の証人として正準に定める。

**前提の強さ。** 本書の前提「V に Mahlo 基数が存在する」は、LNGN の前提より強い。LNGN の公理 U1 はすべての順序数 α について U(α) を要求するので、LNGN が T のモデルをもつには、到達不能基数が真のクラスをなす程度の前提が要る。ただし二つの前提は、宇宙についての主張としては比較できない。Mahlo 基数が一つあっても、宇宙全体で到達不能基数が真のクラスをなすとは限らないからである。比較できるのは無矛盾性の強さで、Mahlo 基数 κ があれば V\_κ は「到達不能基数が真のクラスをなす」ZFC のモデルになるので、本書の前提のほうが無矛盾性の強さで真に強い。本書の比較は V\_κ の中で行う（別紙 B「比較対象の明示」）。前提が強い分、成り立たない可能性も相対的に大きいことは認める。ただし Mahlo 基数は、到達不能基数のすぐ上に位置する標準的な巨大基数であり、その無矛盾性は集合論で広く受け入れられている。

なお、評価モデルを固定しても、S の無矛盾性のような命題そのものの独立性が解消されるわけではない。N の値が一意なのは、あくまで「L で評価する」という意味論的な取り決めの下においてである（Rayo 数が真の宇宙 V を基準とするのと同じ種類の取り決めである）。

## G. φ の意味論的正しさ（無限の場合を含む証明、改訂28）

本別紙では、別紙 B「命題 B の具体化」の主張

```
M ⊨ ∃!x φ(x)   かつ   M ⊨ φ[LNGN_I]
```

を、有限の総当たりに頼らずに示す。以下はすべて L の中での議論である。κ は L で最小の Mahlo 基数、M = (V\_{κ+1})^L、I は別紙 B の候補解釈である。φ の各部品は、付録のプログラムが生成する式そのものを指す。各部品の式が下に書く「条件」をそのまま書き写していることは、生成プログラムの読解と、別紙 B の有限の検証（総当たりと変異テスト）で確かめた。本別紙が新たに示すのは、その条件が**無限の場合にも**意図した関係を定めることである。

### G.1 前提となる事実

**事実 1（M の形）。** M は推移的で、V\_κ ⊆ M である。また、L に属する V\_κ の部分集合はすべて M に属する（M = V\_{κ+1}^L = P(V\_κ^L) ∩ L であり、V\_κ^L は推移的なのでその元はすべて V\_κ^L の部分集合として M に属する）。以下、V\_κ は V\_κ^L を指す。

**事実 2（L の段階）。** L の中で λ が到達不能なら V\_λ = L\_λ である。（V = L の下では、無限基数 μ について H\_μ = L\_μ が成り立ち（標準的な事実。たとえば Jech『Set Theory』第 13 章）、到達不能な λ では V\_λ = H\_λ である。）

**事実 4（M の元の元）。** M ⊆ V\_{κ+1} なので、M の元の元はすべて V\_κ に属する。したがって、M の元から有界量化で取り出した対象（順序対の成分、表の行と値、列の項など）は、すべて V\_κ に属する。M の元のうち V\_κ に属さないもの（階数がちょうど κ のもの。以下「最上位の元」と呼ぶ）が現れうるのは、有界でない量化子で直接動かす変数と、そのような変数から渡される引数だけである。

**事実 3（M の量化子）。** M は真の ∈ をもつ集合構造なので、M ⊨ ψ は「ψ の量化子を M の元だけに制限して L で読んだもの」と同値である。

### G.2 三つの原理

**原理 A（有界量化の絶対性）。** 量化子がすべて ∀u∈v・∃u∈v の形の式（Δ0 式）は、推移的な M と L の間で絶対的である。すなわち引数が M の元なら、M での真偽は L での真偽と一致する。（標準的な事実。M が推移的なので、有界量化子の動く範囲 v の元はすべて M に属する。）

**注意（改訂29）。** 改訂28 までは、空集合・後者・順序対などの基本部品を「Δ0 式」と呼んでいたが、実際の式は有界でない量化子を含んでいた。とくに順序対の判定 pair(p, a, b) は ∀s (s ∈ p ↔ s = {a} ∨ s = {a, b}) という形で、M が {a} や {a, b} を含まないとき（a または b が最上位の元のとき）に偽の陽性が生じた（たとえば a が最上位の元なら p = ∅ で真になる。別の AI による審査で、有限の宇宙 V\_2、a = V\_1、p = ∅ の反例として指摘された）。改訂29 で pair を Δ0 式「p のどの元も {a} か {a, b} であり、{a} と {a, b} がともに p に属する」（{a}・{a, b} であることも有界量化で書く）に改め、付録 `test_pair.py` で、審査の反例で旧版が真・新版が偽になること、V\_3 の上で旧版に 10 件あった偽の陽性が新版では 0 件になること、順序対を補った宇宙で新版が全 12,167 通り一致することを確かめた。旧版の偽の陽性は、たとえば定義の表 DT の項目 r が r = (q, q) の形（定義された集合が自分の定義 (n, τ) と等しい場合）のとき、最上位の y について triple(r, n, τ, y) を真にしてしまい、def\_table を M で偽にしうる。そのような項目が実際に生じるかは確かめていないが、旧版の証明はこの可能性を排除できていなかった。改訂29 の pair では、この種の偽の陽性は原理上生じない。pair の変更により、φ とその部品の記号数はすべて変わった（本書の記号数は改訂29 の値に更新済み）。

**原理 B（有界でない量化子）。** 部品の中の有界でない量化子は、次の四種類に分けられる（各部品の生成コードの All・Ex をすべて確認した）。どの種類でも、量化子が M を動くときの真偽は、L 全体を動くときの真偽と一致する。

- (B0) **値を一意に固定する存在量化**：∃K0 (empty(K0) ∧ …)、∃k (numeral(k, 4) ∧ …)、∃i1 (succ\_of(i, i1) ∧ …)、∃w (is\_omega(w) ∧ …) など。固定される値（∅、数、後者、ω）は V\_κ に属し、M にあり、ほかの値は条件を満たさない。

- (B2) **同値型の全称量化** ∀W (A(W) ↔ B(W))：A(W) も B(W) も「W は V\_κ の元」を含意するもの。たとえば def\_table の ∀t ∀y では、defines が真なら τ は有限関数、y は X の部分集合であり、triple(r, n, t, y) が DT の元 r について真なら t と y は r の成分なので V\_κ に属する（事実 4。ここで pair が Δ0 であることを使う）。zdef の ∀σ（σ ∈ Z または assign）、definable\_set の ∀m（m ∈ S または nat）、冪集合の ∀z（z ∈ a または z ⊆ b、b ∈ V\_κ）、空集合・後者・自然数の判定の量化子（範囲の外の元は条件に関係しない）も同様である。どちらの辺も V\_κ の外では偽なので、量化子の真偽は動く範囲によらない。
- (B3) **表・証人の存在量化**：計算表、証明書、充足関係の集合 TV・S・Z、定義の表 DT、構造の表 ST、段階の表 T・R、O と L の表、有限和と反復の表、割当ての更新 σ′ など。これは原理 C で扱う。

**原理 C（表の一意性と存在）。** 部品が「条件 Ψ(T, 引数) を満たす表 T が存在し、T の値が …」という形のとき、次の二つを示せば、M での真偽は意図した関係と一致する。

- **一意性**：L の中で Ψ(T, 引数) を満たす T（とくに M の元。最上位の元も含む）は、意図した表 T\* に限る。これは表の再帰の順序に関する帰納法で示す。T ∈ M なら、T の行と値は事実 4 により V\_κ に属するので、Ψ の中の T についての条件は、すでに正しさを示した部品に V\_κ の元を渡したものになる（部品の構造に関する帰納法）。
- **存在**：T\* は V\_κ に属する（したがって M に属し、原理 A・B により M でも Ψ を満たす）。これは T\* の階数を評価して示す。

一意性があるので、M の中に意図しない表が紛れ込んで結論を変えることはない。存在があるので、M に表が足りずに偽になることもない。

**合成の規則。** 部品 C(a) について「引数 a が M の元で、付帯条件 S\_C(a) を満たすなら、M ⊨ C(a) ⟺ R\_C(a)（意図した関係）」を示す。付帯条件は主に「a に関係する順序数が κ 未満」である。φ の中で各部品が呼ばれる位置では、引数はより内側の部品によって意図した値に固定されており、付帯条件が満たされることを個別に確認する。

以下、各補題の証明は「原理 A・B で絶対性、原理 C で表」という形にまとめる。番号は別紙 B の部品の順である。

**補題 G1（基本部品）。** 空集合、後者、数詞 numeral(v, k)、順序対、三つ組、推移性、自然数 nat、順序数 ordinal、lookup・pair\_parts・all\_pairs は、引数が M の元なら（最上位の元を含めて）意図した関係と一致する。
*証明。* 順序対（改訂29 の版）、三つ組、推移性、ordinal、lookup・pair\_parts・all\_pairs は Δ0 式なので、原理 A による。三つ組・lookup・pair\_parts・all\_pairs は、有界量化と pair だけで書かれている。残りは有界でない量化子を含むが、M の元を引数とするかぎり Δ0 式と同値である。
- 空集合 ∀e ¬(e ∈ a)：a ⊆ M（推移性）なので、∀e ∈ a ⊥ と同値。
- 後者 ∀u (u ∈ c ↔ u ∈ b ∨ u = b)：b, c ∈ M なら、c の元・b の元・b はすべて M に属するので、「∀u ∈ c (u ∈ b ∨ u = b) ∧ ∀u ∈ b (u ∈ c) ∧ b ∈ c」と同値。
- 数詞 numeral(v, k)：k に関する外側の帰納法で、ExIn と後者だけからなる。
- 自然数 nat の ∀z (z ∈ a ∨ z = a → …)：z は a ∪ {a} ⊆ M を動くので有界と同値。nat と ordinal は基礎の公理の下で意図した集合を特徴づける（第 5.2 節）。□

**補題 G2（ハイパー演算・算術・素数・Encode）。** hyper(n, a, b, c) は、n, a, b, c が自然数のとき c = H(n, a, b) と一致する。加法・乗法・冪・素数・n 番目の素数・有限列・Encode も同様。
*証明。* 表 t の条件は「t のすべての行 ((n, b), v) が、規則のどれか（ハイパー演算の初期値、または t の中の別の行を使った再帰）で正当化されている」という Δ0 条件である。一意性：(n, b) の辞書式順序に関する帰納法で、正当化された行の値は真の H(n, a, b) に等しい。存在：H(n, a, b) の計算に現れる行の全体は有限集合で、遺伝的有限なので V\_ω に属する。素数表・積の表・Encode の表も同じ形である（第 5 節、別紙 B「算術」）。□

**補題 G3（構文：Formula・Formula₋・MetaCode）。** formula(s) は s が ┌L┐ の論理式であることと、formula(s, minus) は Θ を含まない論理式であることと、metacode(n, s) は n = MetaCode(s) であることと一致する。
*証明。* 証明書 C は遺伝的有限な三つ組の集合で、その条件は「各項目がより短い区間（または同じ区間でより少ない個数の列）の項目で正当化される」という Δ0 条件である。健全性：区間の長さと列の個数に関する帰納法で、C の項目はすべて真である。完全性：本当の論理式なら、構文木に現れる区間の全体が証明書になり、遺伝的有限である。MetaCode は Encode の合成であり、Encode は単射なので n から s は一意に定まる（補題 G2）。□

**補題 G4（一意読み）。** ┌L┐ の項と論理式は一意に読める。すなわち、区間 [i, j) が項（または論理式、または n 個の項の列）であるような構文木は高々一つである。
*証明。* 項は自己区切り的である。変数と定数は 1 記号、関数適用は F ( で始まり、F の引数の個数 a が決まっていて、対応する ) で閉じる。したがって、項の真の接頭辞は項ではない（長さに関する帰納法）。これから、項の列の分け方は一意である。論理式も、先頭の記号（⊥、(、¬、∃、関係記号）で規則が決まり、( φ → ψ ) の → の位置は、φ が論理式として一意に区切られることから一意である。□

**補題 G5（充足関係）。** dom ∈ V\_κ、E, Cn, Fn, Rel ∈ V\_κ が構造を表し、s が論理式、σ が s の変数の上の割当てのとき、M ⊨ sat(s, dom, E, Cn, Fn, Rel, σ) ⟺ (dom, E, Cn, Fn, Rel) ⊨ s[σ]（Tarski の意味）。extended 版も同様。
*証明。* sat は「Ns、C、TV、S が存在して ((0, h), σ) ∈ S」と述べる。Ns は s の変数の添字の集合（遺伝的有限、一意）、C は証明書（補題 G3）。TV と S の条件は、C のすべての項目とすべての割当て σ（ガード assign(σ) は σ が Ns から dom への関数であることを述べ、原理 B の (B2)）について、Tarski の条件を課す。一意性：区間の長さに関する帰納法で、TV の値は一意かつ正しく、S は真の充足関係と一致する。C が異なっても、補題 G4 により各項目は同じ構文木の部分なので、根の区間の値は C の選び方によらない。存在：真の TV と S は、遺伝的有限な添字・割当て（dom の有限列）・dom の元からなる集合の部分集合なので、dom ∈ V\_λ（λ < κ）なら V\_{λ+ω} の部分集合となり、V\_κ に属する。□

**補題 G6（IsDefinition・Definable）。** 補題 G5 と同じ条件の下で、definable\_in(s, 𝔄, m) は「m ∈ dom、𝔄 ⊨ IsDefinition(s)、𝔄 ⊨ s[Parameter(m)/x\_0]」（全称閉包、原文の代入規則）と一致する。
*証明。* 原文の代入規則は捕獲を回避するので、代入補題 τ ⊨ P[x\_1/x\_0] ⟺ τ[x\_0 := τ(x\_1)] ⊨ P が成り立つ（標準的な事実）。判定式はこの書き換えを使い、W = Ns ∪ {0, 1} 上のすべての割当てを量化する（原理 B の (B2)）。あとは補題 G5 による。□

**補題 G7（CNF と名前の大小）。** cnf\_lt(i, k) は、自然数 i, k について CNF(i) < CNF(k) と一致する。
*証明。* 分解表と比較表は自然数の有限な表で、条件は Δ0 である（数の計算は補題 G2）。各行はより小さい名前の行だけで正当化されるので、一意性は名前の大きさに関する帰納法、存在は遺伝的有限性による。行の意味の正しさも同じ帰納法で示す。dec(i, a, b) は CNF(i) = ω^{CNF(a)} + CNF(b)（a, b < i）を与える。正規化した先頭 (H, R) は、b = 0 なら (a, 0)、b > 0 で CNF(H(b)) > CNF(a) なら (H(b), R(b))（ω^{CNF(a)} + ω^{CNF(H(b))} + … = ω^{CNF(H(b))} + … という吸収）、そうでなければ (a, b) である。帰納法の仮定から、どの場合も CNF(i) = ω^{CNF(H)} + CNF(R) で、CNF(R) の先頭の指数は CNF(H) 以下になる。したがって CNF(i) と CNF(k) の比較は、カントール標準形の比較と同じく、先頭の指数の比較と、それが等しいときの残りの比較に帰着する。これらはすべてより小さい名前についての比較である。□

**補題 G8（順序数と到達不能基数）。** λ ∈ M のとき、ordinal、is\_omega、func、bij は意図した関係と一致する。また λ ≤ κ なら、regular(λ)・strong\_limit(λ)・inaccessible(λ) は、L における正則性・強極限性・到達不能性と一致する。
*証明。* ordinal・func・bij は Δ0 式である（順序対は改訂29 の Δ0 版）。is\_omega は有界量化と空集合・後者の判定からなり、空集合と後者の判定は補題 G1 により M の元について Δ0 式と同値なので、is\_omega も M の元について Δ0 式と同値である（改訂29 までは「Δ0 である」と書いていたが、構文的には有界でない量化子を含むので改めた。別の AI による審査の指摘）。regular(λ) の有界でない量化子は「f は β から λ への関数」というガードつきの ∀f で、そのような f は β × λ ⊆ V\_κ の部分集合であり、L に属するので M に属する（原理 B）。strong\_limit(λ) の P(β) は「∀z (z ∈ a ↔ z ⊆ β)」で定まる。z は β の部分集合なので、L に属するものはすべて V\_κ に属する。したがって M で計算した P(β) は P^L(β) に等しい。全単射の量化も同様にガードつきである。□

**補題 G9（O と ε0）。** ord\_of(i, x) は、自然数 i について x = CNF(i)（順序数）と一致する。eps0(E) は E = ε0 と一致する。
*証明。* 表 Of は ω 上の関数で、条件は「Of(i) = { Of(k) : k ∈ ω, CNF(k) < CNF(i) }」である（cnf\_lt は補題 G7）。一意性：CNF(i) の値に関する ε0 上の超限帰納法による。値が CNF(i) より小さい名前 k について Of(k) = CNF(k) なら、Of(i) = { CNF(k) : CNF(k) < CNF(i) } となる。CNF は ε0 への全射なので、これは CNF(i) 未満の順序数全体、すなわち CNF(i) である。存在：真の Of は ω × ε0 の部分集合で、V\_κ に属する。ω は is\_omega で一意に固定される。E は Of の値域として一意に定まる。□

**補題 G10（到達不能基数の列）。** lam\_of(β, λ) は、β < ε0 について λ = λ\_β（β 番目の L の到達不能基数）と一致し、λ\_β < κ である。
*証明。* 表 Lf は ε0 上の関数で、Lf(β) は「到達不能、すべての γ < β について Lf(γ) < Lf(β)、Lf(β) 未満の到達不能基数 μ はある γ < β について μ ≤ Lf(γ)」を満たす。これは「すべての Lf(γ) より大きい最小の到達不能基数」と同値である。一意性：β に関する超限帰納法。到達不能性の判定は補題 G8 により L のものと一致する。ここで値は κ 以下の順序数で、M に属する順序数は κ 以下に限られる。存在：κ は L で Mahlo なので、L の到達不能基数は κ の下で非有界である。κ は正則で ε0 < κ なので、λ\_β（β < ε0）はすべて存在して κ 未満であり、sup\_{β<ε0} λ\_β < κ となる。よって真の Lf は ε0 × sup の部分集合で、V\_κ に属する。最小性の量化 ∀μ ∈ λ は有界である。□

**補題 G11（V\_λ）。** λ < κ が順序数のとき、vstage(λ, D) は D = V\_λ（L の V\_λ）と一致する。
*証明。* 表 R は λ+1 上の関数で、R(0) = ∅、R(β+1) は R(β) の冪集合（「∀z (z ∈ X ↔ z ⊆ R(β))」）、極限では和集合である。一意性：β ≤ λ に関する帰納法。冪集合の量化子 ∀z は R(β) の部分集合を動き、R(β) ∈ V\_κ なので、L に属する部分集合はすべて V\_κ に属する（原理 B）。存在：真の R は (λ+1) × V\_{λ+1} の部分集合で、λ + 1 < κ なので V\_κ に属する。□

**補題 G12（構造 U(α) の Θ 以外）。** α < ε0、λ = λ\_α で、SU が β < α について U(β) を値にもつ表のとき、e\_restrict・cn\_ok・rel\_empty・fn\_ok(Fn, D, α, SU) は、別紙 B「構造 U(α)」の意図した解釈とそれぞれ一致する（fn\_ok の Θ の部分は「D 上の関数」という条件のみ）。
*証明。* e\_restrict と rel\_empty は Δ0 である。cn\_ok の ∀t は記号の 4 つ組を動き（B1）、Cn は遺伝的有限な対象と ∅ の組の集合である。fn\_ok の量化子は、記号 t（B1）と、D の元の有限列 w（B2）を動く。U の値は表 SU の値 SU(x)（x ∈ α）で与えられ、lookup は Δ0 である。Fn は、遺伝的有限な記号と D の有限列と D の元の組の集合で、V\_{λ+ω} の部分集合として V\_κ に属する。したがって一意で、M に存在する。□

**補題 G13（定義可能性と L の段階）。** X ∈ V\_κ のとき、defines(n, τ, X, y) は「(n, τ) は (X, ∈) で y を定義する」と一致する。def\_table(X, DT) は DT が X 上の定義の全体であることと一致する。λ < κ のとき、l\_order(λ, D, W) は D = L\_λ かつ W = <\_λ（別紙 B「<\_L と Θ」で定めた Gödel の順序）と一致する。
*証明。* defines は sat（補題 G5）を、領域 X、∈ の制限、空の定数・関数・関係の解釈で使う。量化子は、論理式 s・長さ h・変数の集合（B1）、パラメータ τ と割当て σ（B2）、∈ の制限 E（一意で V\_κ に属する）、z ∈ X（有界）を動く。def\_table の ∀n ∀t ∀y はガードつきである。n は純粋な式の番号（B1）で、defines が真なら t は X への有限関数、y は X の部分集合（B2）である。DT はそれらの組の集合で、V\_κ に属する。
純粋な式の Def は、= を含む一階式の Def と一致する。(X, ∈) が推移的で外延的なら、x = y は ∀z (z ∈ x ↔ z ∈ y) で表せるからである（L\_β はすべて推移的）。step は DT を固定すれば Δ0 である。
l\_order の表 T は λ+1 上の関数で、一意性は β ≤ λ に関する帰納法による。各段の X′ = Def(X) と W′ は DT により一意に定まる。新しい元どうしの順序は「a のある定義が b のどの定義よりも ≺ で小さい」で与えられる。≺ が整列順序なら、これは「最小の定義どうしの比較」と同値である。≺ が整列順序であることは、<\_β が整列順序であることと、パラメータ列の辞書式順序（長さが同じ有限列の辞書式順序は整列順序）から従う。<\_β が整列順序であることは、帰納法で同時に示す（極限では、各段が前の段の終切片への延長なので、和も整列順序）。
存在：L\_β ∈ V\_κ（β ≤ λ < κ）で、<\_β ⊆ L\_β × L\_β なので、T ∈ V\_κ である。λ が L で到達不能なら、事実 2 により L\_λ = V\_λ である。□

**補題 G14（Θ）。** α < ε0、λ = λ\_α、D = V\_λ で、W = <\_λ とする。このとき theta\_L(D, E, Cn, Fn, Rel, W) は、Fn の Θ の部分が別紙 B「<\_L と Θ」の規則に従うことと一致する。さらに、この規則に従う Θ はちょうど一つであり、読み 1 の Henkin 公理をすべて満たす。
*証明。* least\_good の量化子は、割当て σ, σ′, σ₃（B2、ガード assign）と、Z（一意で V\_κ に属する。Z は Ns 上の割当てのうち s を満たすもの全体で、補題 G5 による）を動く。good(a) は D 上の有界量化と割当ての量化からなる。最小元の存在：good な元の集合は空でない。P の真偽が一つの変数 x\_i だけで決まり、しかも定数でないなら、P を満たす割当てがあり、その x\_i の値が good である。そうでなければ、すべての元が good である。W は D の整列順序（補題 G13）なので、最小元が一意に存在する。
Henkin 公理：読み 1 の対象 P（Formula₋ で、自由変数は x\_i だけ）は、真偽が x\_i の値だけで決まる。P が定数でなければ Θ(MetaCode(P)) は P を満たし、定数なら公理は自明である。P は Θ を含まないので、sat が Fn の Θ の部分を参照することはなく、条件は循環しない。□

**補題 G15（構造 U(CNF(i)) の一意性）。** 各自然数 i について、M の中で struct\_full(i, D, E, Cn, Fn, Rel) を満たす組はちょうど一つで、それは候補解釈 I の下での U(CNF(i)) である。
*証明。* α = CNF(i)（補題 G9）。struct\_rec(α, SU) を満たす SU が一意であることを、γ ≤ α に関する帰納法で示す。γ 段では、λ = λ\_γ < κ（補題 G10）、D = V\_λ（補題 G11）、E・Cn・Rel と、Fn の Θ 以外（補題 G12。帰納法の仮定により SU(β) = U(β)、β < γ）、W = <\_λ（補題 G13）、Θ（補題 G14）がそれぞれ一意に定まる。存在：真の表は α+1 上の関数で、値 U(γ) の階数は λ\_γ + ω 未満、sup\_{γ≤α} λ\_γ < κ なので、表は V\_κ に属する。最後の段の五つ組が (D, E, Cn, Fn, Rel) である。□

**補題 G16（f と反復）。** 自然数 n について、f\_val(n, v) は v = f(n)（候補解釈 I の下での原文の f）と一致する。iterate10(a, x) は x = f^10(a) と一致する。
*証明。* 構造の表 ST は n 上の関数で、値は補題 G15 により一意であり、V\_{λ+ω}（λ = sup\_{i<n} λ\_{CNF(i)} < κ）の元の組なので、ST ∈ V\_κ である。definable\_set の ∀m は「m は自然数」というガードつきである（B1）。条件の中の ∃s は論理式（B1）、Definable は補題 G6 による。S は自然数の集合として一意である。各 (i, P) について Definable な m は高々一つ（別紙 E 第 9 項の一意性の補題）で、i と MetaCode(P) は n 未満なので、S は高々 n² 元の有限集合であり、遺伝的有限である。finite\_sum と iterate10 の表は自然数の有限な表で、一意性は表の添字に関する帰納法、存在は遺伝的有限性による。iterate10 の各段の f\_val の引数は自然数なので、上の主張が使える。□

**定理 G（φ の正しさ）。** M ⊨ ∃!x φ(x) かつ M ⊨ φ[LNGN\_I]。
*証明。* φ(x) は「A = H(12, 10, 10) を満たす A があり、iterate10(A, x)」である。補題 G2 により A は 10↑^10 10 に一意に定まり、補題 G16 により x = f^10(A) = LNGN\_I に一意に定まる。□

### G.6 Lean による形式化（改訂36）

別紙 G の三つの原理と、基本部品の絶対性を、証明支援系 Lean 4（バージョン 4.12.0、標準ライブラリのみ、Mathlib なし）で形式化し、Lean のカーネルで検査した（付録 `lean/Moon.lean`、`lean/Export.lean`、`lean_export.py`）。証明に `sorry` はなく、使う公理は Lean の標準の三つ（propext、Classical.choice、Quot.sound）だけである。

- **式と意味。** 式 Fml は生成プログラムと同じ原始記号（∈、=、¬、∧、∀、変数は自然数）をもつ。evalU mem U φ e は、二項関係 mem をもつ任意の型の上で、量化子をクラス U に制限して φ を評価する。U を全体にとれば、制限のない評価になる。
- **原理 A（定理 absolute）。** U が mem について推移的で、割当ての値がすべて U に属するなら、Δ0 式（量化子がすべて ∀v ¬(v ∈ a ∧ p)、a ≠ v の形）は、U に制限した評価と全体での評価で真偽が一致する。
- **原理 B（定理 absoluteF、guarded\_all、iff\_all、pinned\_ex）。** absoluteF は、Δ0 の部分・有界量化に加えて、「U の外の値では本体が真になる」全称量化を許す式の族 AbsF について、同じ一致を示す。空集合・後者・ω の判定はこの族に入る。guarded\_all、iff\_all、pinned\_ex は、別紙 G の (B1)・(B2)・(B0) の型の量化子について、範囲を U に制限しても真偽が変わらない条件を述べた論理的な補題である。
- **原理 C（定理 table\_unique）。** 整礎な添字の上で、「より小さい添字で一致する二つの表は、その添字でも一致する」という局所条件を満たす表は一意である。
- **生成した式そのものの検査。** lean\_export.py は、生成プログラムが作った式を Lean の項に書き出し、あわせて証明項（Δ0 なら IsD0、それ以外は AbsF の導出）を書き出す。順序対（改訂29 の版）、三つ組、推移性、ordinal、func、bij、e\_restrict は Δ0、空集合・後者・is\_omega は AbsF として、すべて Lean で受理された。これにより、これらの部品については「推移的なクラスの上で絶対的である」ことが、手の議論ではなくカーネルで検査された。
- **旧版の順序対。** 改訂28 までの順序対 pair\_old に同じ構成を試すと、外側の ∀s のところで Lean が証明を拒否する。残る目標は「U の外の s について、s = {a} でも s = {a, b} でもない」で、これは一般には成り立たない（別紙 G「注意（改訂29）」の反例）。ここで Lean が示したのは「この構成では証明できない」ことだけで、絶対性が破れることの証明は test\_pair.py の反例による。

**形式化していないもの。** 補題 G2〜G16 の個々の内容（充足関係が Tarski の意味と一致すること、計算表の局所条件が各部品で成り立つこと、L の段階や Θ の性質など）と、数十億記号の部品の式そのものは、Lean では扱っていない。これらは G.3 の手の証明と、G.5 の独立照合に頼る。今回の形式化が保証するのは、それらの証明が共通に使う「道具」（原理 A〜C）と、それを基本部品に当てはめた部分である。

### G.7 補題 G5（充足関係）の Lean による形式化（改訂37）

補題 G5 を Lean 4 で形式化し、カーネルで検査した（付録 `lean/G5.lean`、約 950 行。`sorry` なし、使う公理は標準の三つだけ）。

- **対象。** ┌L┐ の記号（⊥ → ¬ ∃ ( ) と、変数・定数・関数記号・∈・関係記号）、項・項の列・論理式の構文木、記号列への書き出し、Tarski の充足関係（構文木の上の素直な再帰）を定義した。構造は、領域の型、┌∈┐ の解釈、定数・関数・関係記号の解釈からなる。
- **書き写した条件。** 証明書の正当化（parse.py の certificate\_ok：項・論理式・項の列の各規則）、項と列の値の表 TV の条件、充足の表 S の条件（semantics.py の term\_clause・list\_clause・formula\_clause）を、生成プログラムと同じ形で Lean の述語にした。
- **示した定理。**
  - sound：すべての項目が証明書の中で正当化されているなら、各項目は本当の構文木に対応する。記号列が有限であることを使い、尺度 (j, 種類, h − i) の辞書式順序で帰納法を回す（否定の規則だけは同じ j で i を進めるので、第三成分が要る）。
  - term\_ur・terms\_ur・form\_ur：一意読み。同じ位置から読める項・論理式（個数を固定した項の列）は一つしかない。
  - term\_val・terms\_val：TV に載っている値は、項の本当の値に限る。
  - clause\_iff・form\_sat：S は、証明書のどの論理式の項目でも、Tarski の充足関係と一致する。
  - parses\_just・tvtrue\_ok・tvltrue\_ok・strue\_ok：本当の構文解析・本当の値・本当の充足関係からなる表は、すべての条件を満たす（存在）。
  - **sat\_correct**（最終形）：長さ h の記号列が論理式 φ を表すとき、「条件を満たす証明書・TV・S があり、根の項目 (0, h) が証明書と S に入る」ことは、Tarski の意味で φ が σ の下で真であることと同値。これは生成プログラムの sat の主張そのものである。
- **形式化の範囲。** 集合による符号化（順序対・計算表の lookup・有限関数としての割当て）は扱わず、表は Lean の述語として表した。符号化の部分の正しさは、G.6 の絶対性の定理（基本部品）と、有限の検証・独立照合による。割当ては全域関数としたが、論理式の真偽は現れる変数の値だけで決まるので、生成プログラムの有限の割当てと同じである（この同値は形式化していない）。関数記号の解釈は関数とした（生成プログラムでは fn\_ok が関数性を課す）。

### G.11 補題 G3 の数論部分（素数の表・Encode・MetaCode）の Lean による形式化（改訂41）

付録 `lean/Encode.lean`（Dec.lean の素数の定義を使う）。構文の証明書の健全性は G5（G.7）に含まれるので、補題 G3 で残っていたのは「metacode(n, s) が n = MetaCode(s) と一致し、n から s が一意に定まる」という数論の部分である。

**素数についての基本事実（Mathlib なし）。** Euclid の補題（素数 q が ab を割れば a か b を割る。gcd による）、素数の冪を割る素数はその素数、素数は無限にある（n! + 1 の最小の約数）。

**素数の表（arith.py の prime\_table・nth\_prime）。**
- NP i p：p は i 番目の素数（0 番目は 2）。NP\_unique・NP\_total：i ごとにちょうど一つ。NP\_lt：狭義単調増加。
- nth\_correct：(∃ T, 表の条件 ∧ T(i, p)) ⟺ p = p\_i。表の行は「i = 0 で p = 2」か「前の行 (i−1, p₂) があり、p は p₂ より大きい素数で、間に素数がない」（生成した式の条件そのまま）。

**積の表と Encode（prod\_table・encode）。**
- prod\_sound・prod\_true：表の行 (k, P) は P = ∏\_{i<k} p\_{i+1}^{s(i)} と一致し、本当の表は条件を満たす。
- encode\_correct：encode(s, c) の述べる内容は c = Encode(s) = 2^h ∏\_{i<h} p\_{i+1}^{s(i)} − 1 と同値（h は s の長さ）。
- enc\_inj：Encode は単射。2 で割り切れる回数から長さ h が、各 p\_{k+1} で割り切れる回数から各成分が定まる（p\_{k+1} は他の因子を割らない）。

### G.12 生成した式の書き写しの検証（算術の層と MetaCode、改訂42）

G.4 第 1 項は「各部品の式が G.3 の条件を書き写していること」を、プログラムの読解と有限の総当たりで確かめたと述べていた。改訂42 では、算術の層と MetaCode について、これを Lean で機械的に確かめた（付録 `lean/TrCore.lean`、`lean/TrParts.lean`、`lean/TrCheck.lean`、`lean/TrRel.lean`、`lean/TrMeans.lean`。TrParts・TrCheck・TrMeans は `lean_tr_export.py` が書き出す）。

**対象。** empty、succ、trans、pair、is\_one、numeral（0〜4）、nat、triple、hyper\_table、hyper、add・mul・exp、divides、prime、prime\_table、nth\_prime、seqfun、prod\_table、encode、tuple4、metacode の 26 部品。

**方法。**
1. 各部品 X について、生成プログラムが実際に出力する式（下の層もすべて展開したもの）を lit\_X として書き出す。
2. lit\_X のうち、下の層の部品の呼び出しから生じた部分木を、名前つきの関係 .rel に置き換えたもの r\_X を書き出す。
3. **TrRel.lean（手で書いた証明）。** r\_X の意味が、意図した条件と一致することを証明する。下の層の .rel はその部品の意図した条件で解釈する。意図した条件は集合の言葉で読める形に書いた（TrCore.lean の Pair、NatM、HyperTable、PrimeTable、ProdTable、EncodeM、MetaCodeM など）。この証明の実質は、有界量化の形の補助的な量化子（順序対の成分を取り出すための ∃r∈q など）が、順序対の性質により外せることである（L\_lookup、L\_allpairs、L\_parts、L\_triples など）。
4. **TrCore.lean（一般的な補題）。** expand\_ok：.rel を下の層の式に戻す（変数を単射に付け替えて埋め込む）と、意味は保たれる。ev\_rename：単射な変数の付け替えは、割当ての合成に対応する。
5. **TrCheck.lean。** .rel を戻した式 full\_X が、生成プログラムの出力 lit\_X と記号列として完全に一致すること（rfl）と、付け替えが束縛変数を衝突させないこと（check2。改訂44 で一般化、G.14）。これは Python から Lean への書き出しの誤りを検出するもので、生成プログラムそのものの誤りを独立に検出するのは 3 の照合（意図した条件を Lean 側で手で書き、生成された式と突き合わせる）である。
6. **TrMeans.lean。** 以上を合わせて、mean\_X：任意の二項関係 mem の上で、lit\_X の評価は意図した条件と同値。

**意味。** 例えば mean\_encode は「生成プログラムが書き出した encode の式（7,483 節点）は、任意の構造 (α, mem) で、"h が自然数で s は h 上の自然数値の列、積の表 t があり、その h 行目の値 P について c+1 = 2^h · P（掛け算と冪は hyper の表）" という条件と同値」であることを述べる。mean\_metacode（16,731 節点）も同様である。いずれも `sorry` なし、使う公理は標準のものだけ。確認のため、素数の表の条件の一部（「p₂ と p の間に素数がない」）を取り違えた条件で同じ証明を試み、証明が通らないことも確かめた。

**示していないこと。**
- 集合の言葉の条件から自然数の値への移行は、改訂43 で G.13 として形式化した。

### G.19 Lean の定理を読む宇宙（改訂50）

審査で次の指摘を受けた。TrSem.lean の閉包性の仮定 Zax のうち、分出 sep と置換 repl は、Lean の任意の述語 P : α → Prop・任意の関数 F : α → α について述べている。これを外側の宇宙 V で読み、M = (V\_{κ+1})^L、H = (V\_κ)^L とすると、V ≠ L のとき成り立たない。たとえば L に属さない実数 r ⊆ ω について、ω ∈ H なのに {n ∈ ω : n ∈ r} は H に属さない。本書は V = L を仮定していないので、この読み方では Zax は満たされない。指摘は正しい。

**本書の読み方：L の中で読む。** G.12〜G.18 の Lean の定理は、すべて L の中で読む。すなわち、Lean の論理（型の世界は集合、Prop は真偽、関数は集合論的な関数、Classical.choice は大域的な選択）を L の中の集合論で解釈し、型 α を L の V\_{κ+1}（= M）、H を L の V\_κ とする。このとき次が成り立つ。
- L は ZFC のモデルで、κ は L で到達不能（Mahlo）なので、L の中で V\_κ は Zax を任意の述語・関数について満たす。分出は「V\_κ の元の部分集合は V\_κ に属する」から、置換は κ の正則性から、和と冪は κ が強極限であることから従う。L には定義可能な大域的整列順序があるので、Classical.choice の解釈にも困らない。
- 「M の元の元は H に属する」（G.18 の仮定）も、L の中で V\_{κ+1} の元は V\_κ の部分集合なので成り立つ。
- 本書の主張はもともと L での評価についてのものである（第 0 節、比較の前提 1）。数 N は L で評価した Rayo 型の定義で、比較 LNGN\_I < N も L で行う。したがって、Lean の定理を L の中で読むことは、本書の主張に必要な範囲と一致する。V での読み方は必要としない。

**この読み方の前提（機械では検査していない）。** Lean の定理は「任意の型 α と、その上の構造 M : Model α について」の形をしている。これを「L の中の任意の集合 α について」の ZFC の定理として読むのは、メタな議論である。根拠は次の二つ。証明は宇宙の階層を使わず、型 α を一つの変数として扱うだけである。また Lean の論理には集合論での標準的な解釈がある（Prop を真偽、依存型の関数を集合論的な関数とする）。この翻訳そのものは Lean の中では検査していない。

**Zax の分出・置換を使っている箇所。** 参考のため、すべて挙げる。いずれも存在を示す側（完全性・構成）にだけ現れ、意味の照合（健全性の側）には現れない。
- TrSem.lean：割当ての集合（AssignM で分出）。順序対の積（pr で置換と和）。表 TV（真の値の関数 val で置換と和。val は Tarski の値を選択で選ぶ）。表 S（G5 の真偽 Strue で分出し、順序対で置換と和）。
- TrL.lean：∈ の X への制限 E（「(a, b) で a ∈ b」で分出）。

これらは L の中ではどれも問題なく成り立つ。外側の V で読むには、使う述語・関数が (V\_κ)^L の上で定義可能であることを一つずつ示し、Zax を定義可能な述語に制限する必要がある。本書ではその形には直していない。

### G.23 存在の証明と階数の評価（紙の証明、改訂53）

以下は L の中での ZFC の議論である。κ は L で最小の Mahlo 基数、M = V\_{κ+1}、H = V\_κ（いずれも L のもの）とする。存在の側で示すのは次のことである。φ のすべての表・証人について意図した対象をとると、それらは V\_κ に属し、したがって M に属する。また、M の中で読んだ条件を満たす。条件を M の中で読んでよいことは G.2 の原理 A・B による。G.3 の補題 G8〜G16 の「存在」の部分を、階数の評価と再帰の非循環性まで含めてここにまとめる。

**階数についての事実。** rank(x) < μ ⟺ x ∈ V\_μ。λ が極限順序数なら、次が成り立つ。
- (R1) a, b ∈ V\_λ なら {a}, {a, b}, (a, b) ∈ V\_λ。また、rank((a, b)) = max(rank a, rank b) + 2。
- (R2) V\_λ の元の有限列（n から V\_λ への関数を順序対の集合としたもの）は V\_λ に属する。
- (R3) V\_λ の部分集合は V\_{λ+1} に属する。μ < λ なら、V\_μ の部分集合は V\_λ に属する。
- (R4) 遺伝的有限な集合（数、記号の 4 つ組、自然数の有限な表）は V\_ω に属する。

**証人と階数の評価。**

**注（DT の階数、改訂55 で訂正）。** 改訂54 までは DT\_β の階数を β + 5 以下としていたが、誤りだった（審査の指摘）。式の番号 n は自然数全体にわたる。たとえば β = 0（L\_0 = ∅）でも、(x\_0 ┌∈┐ x\_0)、¬¬(x\_0 ┌∈┐ x\_0)、¬¬¬¬(x\_0 ┌∈┐ x\_0)、… はどれも ∅ を定義する（改訂57 までは = を使った例を挙げていたが、def\_code の純粋な式は = を含まないので改めた。審査の指摘）。そのため DT\_0 には無限個の番号が現れ、DT\_0 の階数は ω 以上になる。正しい評価は次のとおりである。DT\_β の元 ((n, τ), y) について、n ∈ ω、τ は ω の元を添字とし L\_β ⊆ V\_β の元を値とする有限関数、y ⊆ L\_β である。各成分の階数は max(β, ω) + 3 未満で、三つ組の階数は max(β, ω) + 7 未満になる。よって rank(DT\_β) ≤ max(β, ω) + 7 < max(β, ω) + ω である。β ≤ λ < κ で κ は極限順序数なので、この上界も κ 未満である。DT\_β は l\_order の表 T の行には含まれず、step の中の存在量化の証人として現れるだけである。したがって、T の階数 λ + 5 以下という評価は変わらない（λ ≥ ω）。

すべての階数は κ 未満なので、証人は V\_κ ⊆ M に属する。U(γ) の階数は次のとおりである。λ = λ\_γ は極限順序数である。D = V\_λ の階数は λ である。E ⊆ V\_λ（R1）。Cn ⊆ V\_ω。Fn の元 ((t, w), v) は、t ∈ V\_ω、w ∈ V\_λ（R2）、v ∈ V\_λ（下の再帰の帰納法の仮定。改訂54 で補題 R の引用を改めた）なので V\_λ に属し、Fn ⊆ V\_λ である。Rel = ∅。よって五つの成分はどれも V\_{λ+1} に属し、組 ((D, E), (Cn, (Fn, Rel))) の階数は λ + 7 以下である（R1 を 3 段）。表の行 (γ, U(γ)) の階数は λ\_γ + 9 以下で、λ\_γ ≤ λ\_α なので SU の階数は λ\_α + 9 以下である。

**補題 R（閉包条件。Lean の struct\_closed と同じ内容。改訂61 で Lean でも証明した）。** α, SU ∈ M が M の中で struct\_rec(α, SU) を満たすとする（SU は意図した表とは限らない）。このとき、SU(γ) = ((D, E), (Cn, (Fn, Rel))) となる各 γ について、∅ ∈ D であり、x ∈ D が順序数で x ∈ γ なら SU(x) ∈ D である。
*証明。* γ に関する ∈-帰納法による。level の条件から次が分かる。lam\_of(γ, λ) なので、λ = λ\_γ は L の到達不能基数である（補題 G10）。vstage(λ, D) なので、D = V\_λ である（補題 G11。一意性は Lean の vstage\_unique、意図した表の存在は上の表）。λ > 0 なので ∅ ∈ D である。

x ∈ D が順序数で x ∈ γ とし、SU(x) が存在するとする（存在しなければ主張は空である）。SU(x) = ((D′, E′), (Cn′, (Fn′, Rel′))) とおく。
- lam\_ok の条件「g ∈ β なら Lf(g) ∈ Lf(β)」により、λ\_x < λ\_γ である（x ∈ γ ∈ ε0）。
- D′ = V\_{λ\_x} である。
- E′ ⊆ D′ × D′、Cn′ ⊆ V\_ω × {∅}、Rel′ = ∅ である。
- Fn′ の元は fn\_ok の fn\_entry により、((t, w), v) の形である。ここで t は記号の 4 つ組、w は D′ の元の有限列である。v は次のいずれかである。
  - f の行なら ∅。
  - Θ の行なら D′ の元。
  - U の行なら、y が順序数で y ∈ x のとき SU(y)、そうでなければ ∅（y ∈ D′ は w の唯一の項）。帰納法の仮定（x について）により、この SU(y) は D′ に属する。

したがって、上の階数の評価と同じ計算により、SU(x) の階数は λ\_x + 7 以下で、λ\_γ 未満である（λ\_γ は極限で λ\_x < λ\_γ）。よって SU(x) ∈ V\_{λ\_γ} = D である。□

ここで使った lam\_of・vstage・fn\_ok の条件は、M の中で読んだものである。どれも Δ0 か、原理 B のガードつきの量化子で書かれているので、L で読んだものと一致する（補題 G8〜G12）。

**U(α) の再帰と階数の同時帰納法（改訂54 で書き直し）。** 改訂53 では、構成の途中で「U(x) ∈ D は補題 R の計算による」と書いた。補題 R は struct\_rec をすでに満たす表についての主張なので、構成の途中で引くと循環して見える。改訂54 では、補題 R を構成に使わない。代わりに、階数の上界を再帰と同時に帰納法で示す。補題 R は、構成とは別に、M の中の任意の struct\_rec の証人に対する主張として使う（G.22 の仮定 hC。改訂61 からは Lean の struct\_closed）。

U(γ)（γ ≤ α）を、L の中で γ に関する超限再帰で定め、同時に次の主張 (♯γ) を示す。

> (♯γ) U(γ) は五つ組 ((D, E), (Cn, (Fn, Rel))) で、D = V\_{λ\_γ}、rank(U(γ)) ≤ λ\_γ + 7。

各段 γ では、U↾γ = { (β, U(β)) : β < γ } が与えられ、帰納法の仮定としてすべての β < γ で (♯β) が成り立つとする。次の順に定める。
1. λ = λ\_γ（Lf の値。U によらない）。β < γ なら λ\_β < λ\_γ（L の定義）。
2. D = V\_λ、E = ∈↾D、Cn = { (c, ∅) : c は定数記号 }、Rel = ∅（λ だけによる）。
3. Fn₀ = f の行 ∪ U の行。
   - f の行は、各関数記号 f と、D の元の正しい長さの列 w についての ((f, w), ∅) である。
   - U の行は、x ∈ D についての ((U, ⟨x⟩), v\_x) である。v\_x は、x が順序数で x ∈ γ なら U(x)、そうでなければ ∅ とする。
   - Fn₀ は D と U↾γ だけで決まる。x ∈ γ のとき、帰納法の仮定 (♯x) により rank(U(x)) ≤ λ\_x + 7 < λ\_γ（λ\_γ は極限で λ\_x < λ\_γ）なので、U(x) ∈ D である。
4. W = <\_λ。λ だけによる。D 上の狭義の整列順序である（補題 G13。下の「存在の照合」で T\* が l\_order を満たすことを確かめたので、Lean の lorder\_wo をこの T\* に適用してもよい）。
5. Θ の行。G5 の構造 𝔄⁰ = (D, ∈, 定数はすべて ∅, f と U は Fn₀ の値, Θ はすべて ∅, 関係はすべて空) をとる。各 m ∈ D について、m が Formula₋ の式 s（G5 の式 φ\_s）の番号なら、v\_m は「𝔄⁰ で φ\_s について good（G14 の意味）な元のうち W で最小のもの」とする。そうでなければ v\_m = ∅ とする。good な元は存在し（G14 の good\_exists）、W は整列順序なので、最小元は一つに定まる。
6. Fn = Fn₀ ∪ { ((Θ, ⟨m⟩), v\_m) : m ∈ D }。U(γ) = ((D, E), (Cn, (Fn, Rel)))。

(♯γ) の証明。D = V\_λ は手順 2 による。E ⊆ V\_λ（R1）、Cn ⊆ V\_ω である。Fn の元 ((t, w), v) は、t ∈ V\_ω、w ∈ V\_λ（R2）、v ∈ V\_λ なので、V\_λ に属する。v ∈ V\_λ となる理由は、f の行は ∅、U の行は手順 3、Θ の行は v\_m ∈ D だからである。よって五つの成分は V\_{λ+1} に属し、組の階数は λ + 7 以下である（R1 を 3 段）。□

**非循環性。** どの手順も、U(γ) 自身や U(δ)（δ ≥ γ）を参照しない。Θ の値（手順 5）は Fn₀ だけから作った構造 𝔄⁰ で決め、Fn の Θ の行を参照しない。各手順は L の中で定義可能な操作なので、これは置換公理による通常の超限再帰である。SU\* = { (γ, U(γ)) : γ ≤ α } は L の集合として存在し、(♯) により階数は λ\_α + 9 以下である。

### G.25 存在の側の自己点検（改訂56）

改訂55 の審査では、定理 G の完成を認定する前に、G.23 が引く存在の補題と G.23 との整合性を確かめたいとされた。それに先立って、こちらで点検した。直したのは二点で、G.23 の l\_order の照合に反映した。

**補題 P（純粋な式の Def）。** X が推移的な集合なら、通常の Def(X) と、純粋な式による Def は一致する。通常の Def(X) は、= と ∈ を使う一階の式と、X の元のパラメータで定義される X の部分集合の全体である。純粋な式は、┌L┐ の式のうち記号が変数・┌∈┐・論理記号・括弧だけのものである。
*証明。*
- ⊇：純粋な式は通常の式なので、純粋な式で定義される集合は Def(X) に属する。
- ⊆：通常の式 ψ(x\_0, p⃗) の原子式 u = v を、新しい変数 z を使った ∀z (z ∈ u ↔ z ∈ v)（┌L┐ では ¬・→・∀ で書く）に置き換えた純粋な式を ψ′ とする。X が推移的なら、u, v ∈ X について u = v ⟺ ∀z ∈ X (z ∈ u ↔ z ∈ v) である（外延性。u, v ⊆ X）。よって (X, ∈) で ψ と ψ′ は同値である。
- パラメータの割当て：defines の τ は、式に現れる 0 以外のすべての変数（束縛変数を含む）に値を与える。束縛変数への値は充足に影響しない（sat は量化のたびに割当てを更新する）。X ≠ ∅ なら、束縛変数には X の任意の元を与えればよい。
- 変数の付け替え：x\_0 以外の自由変数を、ψ′ の自由変数の添字に合わせて付け替える。

以上により、y ∈ Def(X) ⟺ ある純粋な式の番号 n とパラメータ τ について defines(n, τ, X, y)（X ≠ ∅ のとき）。□

**補題 Z（最初の段 L\_0 → L\_1）。** X = ∅ のとき、M で defines(n, τ, ∅, y) が成り立つことと、「n が純粋な式の番号で、その式に x\_0 以外の変数が現れず、τ = ∅、y = ∅」は同値である。とくに { y : ∃n ∃τ defines(n, τ, ∅, y) } = {∅} = L\_1 である。
*証明。* defines の条件を直接読む。
- 割当て assign(K, ∅, τ) は、K = ∅ のときに限り τ = ∅ で成り立つ。K は 0 以外の変数の集合である。
- y ⊆ X = ∅ なので y = ∅ である。
- 「∀z ∈ X (z ∈ y ⟺ …)」は空虚に真である。
- E = ∈↾∅ = ∅ は e\_restrict を満たす。
- 残る条件（formula₋、metacode、seq\_with、pure、var\_set）は式 s だけに関する条件である。
- (x\_0 ┌∈┐ x\_0) のように x\_0 しか現れない純粋な式は存在する。

よって、def\_code(n) を満たす番号で、変数が x\_0 だけの式の番号は、すべて (n, ∅, ∅) として DT\* に入る。また、DT\* の y はすべて ∅ である。L\_1 = {∅} = Def(∅) とも一致する。<\_1 は {∅} 上の空の順序で、step の順序の条項（新どうしは new\_less。a = b = ∅ だけ）は、W1 = ∅ と new\_less(∅, ∅) の偽で満たされる。new\_less(∅, ∅) は「∅ のある定義が ∅ のどの定義よりも小さい」で、同じ定義どうしを比べると成り立たない。この段では、Lean の defines\_iff（X ≠ ∅ を仮定する）を使わない。□

- 自由変数の集合。∀ の束縛を数えて追う。
- 記号数。

検査器そのものも、次の二つで確かめた。
- 正しい式と壊れた式（閉じ括弧の欠落、余分な記号、変数で始まる列など）を正しく判定する。
- 部品 struct\_full（359,495,134 記号）で、記号数と自由変数が生成プログラムの値と一致する。

**結果（2026-10-21、約 7 分）。**

```
L-式として正しい：はい
記号数 = 19,229,718,256
自由変数 = {x}
記号ごとの数：x 774,887、′ 19,226,417,979、¬ 473,890、∧ 319,153、∀ 136,579、∈ 232,124、= 87,030、( 638,307、) 638,307
入れ子の最大の深さ 596、変数の ′ の最大個数 44,481、全文 57,684,403,816 バイト
終了コード 0
```

最終式は、第 2 節の文法でちょうど一つの L-式である。記号数 19,229,718,256 と自由変数 {x} は、生成プログラムの計数（別紙 B）と一致した。記号のほとんど（99.98%）は変数のプライムである。生成プログラムは束縛変数に毎回新しい番号を割り当てるので、変数名が長くなる（fol.py の冒頭の説明）。

**この検査の位置づけ。** 確かめたのは構文、すなわち整形・記号数・自由変数だけである。各部品が意図した条件を書き写していることは、Lean による部品ごとの証明（G.12〜G.21）が担う。Lean で組み立てた式と全文との一致は、ハッシュ値の照合（G.21）が担う。この検査は、その二つとは独立に、全文が第 2 節の意味での L-式で、長さが本文の値どおりであることを確かめる。
