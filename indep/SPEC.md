# 仕様：┌L┐ の構文・充足関係・定義可能性・Θ の答え合わせ役

この仕様だけを読んで、Python 3（標準ライブラリのみ）で `reference.py` を書いてください。
既存のコードは参照しないでください（目的は、独立に書かれた答え合わせ役を得ることです）。
有限の小さな構造で総当たりしてよく、速さは問いません。正しさと読みやすさを優先してください。

## 1. 記号

記号は自然数の 4 つ組 `(a0, a1, a2, a3)` で表す（Python のタプル）。

| 記号 | 4 つ組 |
| --- | --- |
| ⊥ | (0,0,0,0) |
| → | (1,0,0,0) |
| ¬ | (2,0,0,0) |
| ∃ | (3,0,0,0) |
| ( | (4,0,0,0) |
| ) | (5,0,0,0) |
| 定数 c_i | (6,0,i,0) |
| 変数 x_i | (7,1,i,0) |
| 関数 U（引数 1） | (8,2,0,1) |
| 関数 Θ（引数 1） | (8,3,0,1) |
| 関数 f_{a,i}（引数 a） | (8,4,i,a) |
| 関係 ∈（引数 2） | (9,5,0,2) |
| 関係 r_{a,i}（引数 a） | (9,6,i,a) |

これ以外の 4 つ組（たとえば (8,2,0,0)、(8,3,5,1)、(9,5,0,1)）は記号ではない。

## 2. 文法

記号の列（タプルのリスト）について：

- 項：`x_i` ／ `c_i` ／ `F ( t_1 … t_a )`。F は関数記号で a はその引数の個数（4 つ組の第 3 成分 a3）。引数の間に区切り記号はない（並置）。a = 0 のときは `F ( )`。
- 原子式：`⊥` ／ `( t_1 ∈ t_2 )` ／ `R ( t_1 … t_a )`（R は ∈ 以外の関係記号、a はその引数の個数）。
- 論理式：原子式 ／ `( φ → ψ )` ／ `¬ φ` ／ `∃ x_i ( φ )`。
- Formula：論理式全体。Formula₋：Θ を一つも含まない論理式。

## 3. 構造と充足関係

構造 A は次の Python オブジェクトで与える。

- `dom`：領域（ハッシュ可能な値のリスト。空でない）
- `E`：┌∈┐ の解釈。dom の元の順序対 (a, b) の集合
- `Cn`：定数記号 → dom の元 の辞書（使われる定数はすべてある）
- `Fn`：(関数記号, 引数のタプル) → dom の元 の辞書（使われる関数記号と dom の引数の組はすべてある）
- `Rel`：(関係記号, 引数のタプル) の集合（成り立つものを集めたもの）

割当て σ は 変数の添字（自然数）→ dom の元 の辞書。

Tarski の意味論：⊥ は偽、( t1 ∈ t2 ) は (値1, 値2) ∈ E、R(…) は (R, 値の組) ∈ Rel、→ ¬ は通常どおり、
∃x_i(φ) は「dom のある元 a について σ[i := a] ⊨ φ」。

## 4. 自由変数と全称閉包

「A ⊨ φ」（割当てを指定しない場合）は**全称閉包**で読む：φ の自由変数へのすべての割当てで真。

## 5. 代入と IsDefinition・Definable（原文どおり）

- 代入 φ[x_j / x_i]（変数 x_i の自由な出現を変数 x_j に置き換える）：
  原文の規則では、∃y(Q) に代入するとき、代入する項（ここでは x_j）に y が現れるなら（y = x_j なら）、
  まず y を「φ・x_i・x_j のどれにも現れない最小の添字の変数」に付け替えてから代入する。
  ∃x_i(Q) の中には代入しない（x_i は束縛されている）。
- IsDefinition(P) は論理式 `∃x_0 ( P ∧ ∀x_1 ( P[x_1/x_0] → x_1 = x_0 ) )`。
  ∧, ∀ は略記、x_1 = x_0 は「同じ元である」（領域の元としての等号）と解釈する。
  注意：P が x_1 を自由変数としてもつと、外側の ∀x_1 がそれを捕まえる（そのまま原文どおりに扱う）。
- Definable(m, A, P) ⟺ m ∈ dom かつ A ⊨ IsDefinition(P)（全称閉包）かつ A ⊨ P[x_0 := m]
  （x_0 の自由な出現を m を表す新しい定数に置き換えたもの、すなわち x_0 に m を割り当てて、他の自由変数について全称閉包）。

## 6. 定義可能な部分集合

X は有限の推移的集合（Python の frozenset で表した遺伝的有限集合）、(X, ∈) を構造とみる（E は本物の ∈、定数・関数・関係は使わない）。
「純粋な式」= 変数・∈・論理記号・括弧だけからなる論理式。
純粋な式 P とパラメータ τ（P に現れる変数の添字のうち 0 以外の**すべて**を定義域とする、X への関数。束縛変数の添字も含む）について、
`defines(P, τ, X) = { z ∈ X : (X, ∈) ⊨ P [x_0 := z, 他は τ] }`。
τ の定義域がちょうどその集合でなければ「定義しない」（None を返す）。

## 7. Θ の規則

構造 A（有限）、A の領域上の整列順序（リスト `order`、先頭が最小）、式 P について、Θ の値 `theta(P, A, order)` を：

- P が Formula₋ でなければ、Θ の値は「領域の元のうち、Python で frozenset() に等しいもの」（それがなければ None）。
- そうでなければ、Ns = P に現れる変数の添字全体（自由・束縛を問わない）、σ は Ns 上の割当て全体を動くとし、
  Z = { σ : σ ⊨ P } とする。
  - dep_only(i) ⟺ σ(i) = σ′(i) である任意の σ, σ′ について (σ ∈ Z ⟺ σ′ ∈ Z)
  - good(a) ⟺ Ns のどの i についても、「dep_only(i) かつ Z ≠ ∅」ならば「すべての σ で σ[i := a] ∈ Z」
  - Θ の値は good な元のうち order で最初のもの。

あわせて `henkin_ok(P, A, value)` を書いてください：P が Formula₋ で、自由変数が高々一つ x_i（i は何でもよい）のとき、
「P を満たす x_i が存在するなら、x_i := value で P が真」（閉じた式なら自明に真）。それ以外の P では True。

## 8. 提出するもの

`reference.py` に次の関数：

- `is_formula(seq, minus=False) -> bool`
- `free_vars(seq) -> set[int]`（seq は論理式）
- `sat(seq, A, sigma) -> bool`（sigma は seq の自由変数を少なくとも含む辞書）
- `holds(seq, A) -> bool`（全称閉包）
- `subst_var(seq, i, j) -> list`（φ[x_j/x_i]、原文の規則）
- `is_definition(seq, A) -> bool`、`definable(m, A, seq) -> bool`
- `defines(seq, tau, X) -> frozenset | None`
- `theta(seq, A, order)`、`henkin_ok(seq, A, value) -> bool`

構造 A は `types.SimpleNamespace(dom=..., E=..., Cn=..., Fn=..., Rel=...)` などで受け取れるようにしてください（属性アクセス）。
最後に、自分で考えた小さな自己テスト（`if __name__ == "__main__":`）を付けてください。
