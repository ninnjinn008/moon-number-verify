## 9. 次の段とその整列順序

入力：
- `X`：有限集合（frozenset）。
- `order`：X の元を小さい順に並べたリスト（X の整列順序）。
- `defs`：X 上の「定義」の一覧。各要素は `(n, tau, y)` で、n は自然数（式の番号）、tau は 自然数 → X の元 の辞書（パラメータ）、y は frozenset（その定義が定める集合）。

出力 `next_level(X, order, defs)`：
- 次の段 `X1` = defs に現れるすべての y の集合（frozenset）。
- その整列順序 `order1`（リスト）。規則は次のとおり。
  1. X の元どうしは `order` のとおり。
  2. X の元は、X にない新しい元よりすべて前。
  3. 新しい元 a, b は「最小の定義」で比べる。a の最小の定義とは、y = a となる defs の要素のうち、次の順序で最小のもの：
     (n, tau) ≺ (n′, tau′) ⟺ n < n′、または n = n′ かつ tau が tau′ より辞書式に小さい。
     辞書式の比較：tau と tau′ の定義域は同じとしてよい。添字（辞書のキー）の小さい順に見て、最初に値が異なる添字 k で、
     tau[k] が tau′[k] より `order` で前なら tau が小さい。
  （X の元が X1 に含まれない場合は考えなくてよい。）
戻り値は `(X1, order1)`。

## 10. 構造 U(γ) の中の ┌U┐ の値

入力：
- `D`：有限集合（構造 U(γ) の領域）。
- `gamma`：自然数（フォン・ノイマン順序数としての γ）。
- `SU`：自然数 β → 集合 の辞書（β < γ について、構造 U(β) を表す集合）。

出力 `u_values(D, gamma, SU)`：D の各元 x について、
- x がフォン・ノイマン順序数（frozenset で表した自然数 0 = frozenset()、k+1 = k ∪ {k}）で、x < γ なら `SU[x の値]`、
- それ以外なら `frozenset()`
を値とする辞書 `{x: 値}`。
